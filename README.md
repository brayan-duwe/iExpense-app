# iExpense 💸

*This project was built using SwiftUI.*

This is a simple way to registrate all your expenses. All you have to do is: click on the top-left button "+" to add some expense, and you can classify them into personal or business expenses.


## Project files

* [ContentView.swift](/iExpense/ContentView.swift) - Main app
* [AddView.swift](/iExpense/AddView.swift) - Second view (Add Expenses view)
