# iExpense 💸

*This project was built using SwiftUI.*

This is a simple way to record all your expenses. Add and categorize your expenses as personal or business, with color-coded amounts for quick reference.

## Features
* Add expense via the **+** button
* Classify as **Personal** or **Business**
* Color-coded by amount: 🔵 ≤ $10 · 🟢 $10–100 · 🟠 > $100


## Project files

* [ContentView.swift](/iExpense/ContentView.swift) - Main app
* [AddView.swift](/iExpense/AddView.swift) - Add Expense view
